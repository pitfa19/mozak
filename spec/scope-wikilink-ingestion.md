# Scope wikilink ingestion v1

`mozak scope ingest-links SCOPE_ROOT SOURCE_ROOT OBSERVED_REVISION PLAN_JSON OUTPUT_ROOT` performs one owner-approved, append-only projection update. The plan is schema version 1 and pins the exact input `scope.json` SHA-256, one 40-character observed revision, an existing owner-selected `scope_id`, one explicit history entry, selected existing note input IDs, and explicit inclusions.

Each inclusion declares exactly `input_id`, `kind`, `source_path`, `source_sha256`, and `media_type`. Source paths and link targets use a strict ASCII-only relative-path contract so case-fold collision checks are complete and deterministic. The command does not scan or recurse. It resolves every wikilink and embed found in only the selected existing notes against the closed set of existing registered inputs plus declared inclusions, using the same exact path, extensionless Markdown path, basename, and stem matching as current KB parity. Exactly one target must match and every inclusion must be used. Empty or whitespace-only links, aliases, headings, vault-root prefixes, unsafe paths, non-ASCII paths, and control characters are unsupported and rejected.

Before writing, the command validates the input Scope, plan pin, revision, IDs, append-only chronology, ASCII source-path casefold uniqueness, canonical absolute non-symlink source root and path chain, every selected source and inclusion byte hash, all link resolutions, inclusion use, and output absence. Output and sibling staging paths must be outside both the input Scope and source roots. Existing entries include dangling symlinks. It then reconstructs a new Scope root solely from manifest-declared project files and content-addressed objects, recomputes included note metadata, sorts manifest collections deterministically, stages beside the output, validates the staged Scope, and atomically renames it. Any staging or rename failure removes staging. Source and input roots are never mutated.

The deterministic JSON receipt includes `auto_discovery:false`, `authority:"source_vault_remains_authoritative"`, the plan hash, input and output manifest hashes, observed revision, selected scope, and added input IDs. The command never transfers authority and is not a pilot or bulk migration mechanism.

Schema: [`scope-wikilink-ingestion-plan.schema.json`](scope-wikilink-ingestion-plan.schema.json).
