# Portable task ledger

## Intent

Create a repository-local ledger that helps a small team track bounded work without depending on a hosted service.

## Desired outcomes

- Contributors can record, inspect, and complete tasks using versioned project files.

## Boundaries

- The first version does not provide accounts, billing, notifications, or network synchronization.

## Assumptions

- The repository is writable while a contributor updates the ledger.

## Open questions

- Which text format should be canonical for task records?
