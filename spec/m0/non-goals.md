# Alpha non-goals

- Autonomous acceptance of model-generated claims.
- Multi-user tenancy or role administration beyond one local owner and delegated agents.
- Multi-device synchronization or conflict-free replication.
- Hosted operation, paid connectors, or required cloud infrastructure.
- Broad external write access, purchases, messages, deployment, or account mutation.
- GNNs, learned graph maintenance, graph diffusion, or mandatory vector retrieval.
- A custom agent runtime or Jcode fork.
- Final UI design.
- Final production database schema or production Rust implementation.
- Automatic key recovery, password reset, or secret escrow.
