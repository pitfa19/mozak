# MOZAK wordmark and typography options

## Image-generated wordmark concept

`mozak-wordmark-generated-dark.png` pairs a custom MOZAK wordmark with a generated rendition of the existing brain-circuit mark. The letters use chamfered geometric forms, lavender accents through the Z and K, and a gold node inside the A. This is an image-generated concept, not a font or editable vector.

Use this as a title-card or intro/outro design option. It does not replace the official SVG assets. For exact icon fidelity or layer animation, use `mozak-mark-transparent.svg` as the source of truth and recreate the lettering as vector paths. The generated PNG has a dark background, not transparency. No transparent variant has been produced.

## Typography alternatives

`font-specimen.png` preserves the six comparison cards as options, not an approved final selection:

1. Instrument Serif
2. Bricolage Grotesque
3. Chakra Petch
4. Syne ExtraBold
5. Space Mono
6. Space Grotesk with Plus Jakarta Sans

Font files are in `fonts/`. JetBrains Mono and Outfit also remain available there. Keep readable UI and caption typography separate from decorative logo lettering. Existing videos retain their current typography.

## Production handoff

Review this concept alongside the font alternatives before choosing the final treatment. Keep the original icon palette: dark slate, lavender, gold, and green. Do not substitute a pink/cyan pixel-art brain. The generated logo image contains only the mark and wordmark, with no tagline or version badge.
