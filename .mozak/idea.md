# MOZAK idea

## Intent

Build a provider-neutral Project Framework that operates a project from an idea through codebase-aware research and dependency-graph implementation planning. External agents execute research pipelines and work packets, while the framework preserves evidence, decisions, acceptance contracts, and observed results.

## Desired outcomes

Deliver the smallest complete Project Framework workflow through ordered, tested packets. After project-local workflows are proven, build the MOZAK Meta KB to ingest project knowledge releases and reason across projects.

## Boundaries

Do not modify the first external onboarding project before the framework release gate is complete. Generated or external content may propose changes but cannot authorize acceptance or external effects.

## Assumptions

Provider-neutral local contracts, deterministic validation, and independent evidence are sufficient foundations for later agent integrations and project knowledge releases.

## Open questions
